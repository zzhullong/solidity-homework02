# BeggingContract 讨饭合约（作业二）

MetaNodeAcademy LearningRoadmap `contract/homework02.md` 的实现，使用 Foundry 开发与测试。

## 功能

- `donate()`：向合约捐赠 ETH，记录捐赠者地址与累计金额
- `withdraw()`：合约所有者提取全部资金
- `getDonation(address)`：查询某个地址的捐赠金额
- 可选挑战：Donation 事件、Top3 捐赠排行榜、捐赠时间窗口

## 运行测试

```bash
forge test -vvv
```
